# Lefleat

**Lefleat** — це інтерактивний веб-додаток для роботи з мапою Львова на базі [Leaflet.js](https://leafletjs.com/). Проєкт написаний на **TypeScript**, зібраний через `tsc`, і призначений для створення, редагування та збереження географічних об’єктів прямо в браузері.

🌐 **Демо (локально):** відкрий `index.html` через `python3 -m http.server 8090` після збірки, або використовуй `npm run serve`.

---

## Призначення

Lefleat створено для роботи з історичною та культурною географією Львова. Користувач може:

- позначати об’єкти на мапі (будівлі, пам’ятки, локації);
- малювати лінії, полігони, кола, прямокутники та текстові позначки;
- додавати історичні підкладки (растрові зображення на мапі);
- зберігати роботу локально в браузері (`localStorage`);
- імпортувати та експортувати дані у форматах GeoJSON і KMZ;
- використовувати AI-асистента для швидкого пошуку та позначення місць.

## Швидкий старт

### Вимоги

- Node.js 18+
- npm або інший package manager

### Встановлення

```bash
git clone https://github.com/olehdutko/leaflet.git
cd lefleat
npm install
```

### Збірка та запуск

```bash
npm run build      # скомпілювати TypeScript
npm run serve      # запустити локальний сервер на http://localhost:8090
```

Для розробки:

```bash
npm run dev        # build + lint + prettier check
```

## AI-асистент

AI-асистент дозволяє швидко знаходити місця за назвою та додавати їх на мапу:

1. Натисніть кнопку 🤖 у top bar.
2. Введіть запит, наприклад: «Боїмська каплиця».
3. Асистент запропонує варіанти з OpenStreetMap.
4. Оберіть потрібний — маркер з’явиться на мапі.

---

## Історичні підкладки

1. Відкрийте панель шарів.
2. У секції «Історичні підкладки» натисніть 📷.
3. Оберіть зображення.
4. Позиціонуйте його на мапі, масштабуйте та обертайте за потреби.
5. Підкладка зберігається в `localStorage` і відновлюється при перезавантаженні.

---

## Зберігання даних

Усі шари, об’єкти та підкладки зберігаються в `localStorage` браузера під ключами з префіксом `lefleat_`. Дані не надсилаються на сервер.
