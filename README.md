# Lefleat - Мапа Львова на Leaflet

Веб-додаток для роботи з інтерактивною картою Львова, побудований на Leaflet.js з підтримкою різних типів об'єктів та шарів.

## Особливості

- 🗺️ Інтерактивна карта Львова
- 📍 Маркери, лінії, полігони
- 🖼️ Підтримка зображень
- 📁 Імпорт/експорт KMZ, GeoJSON
- 🔍 **Розширений геопошук** з автодоповненням та локалізацією
- 🔍 **Глобальний пошук об'єктів** з групуванням та виділенням
- 📏 Інструменти вимірювання
- 💾 Автоматичне збереження в localStorage
- 🏗️ **Модульна архітектура** з принципами SOLID

## Правила розробки

### index.js/index.ts
- **В index.js НЕ повинно бути ніякого JS коду**
- **Тільки імпорти та мінімальна ініціалізація**
- Всі функції та логіка повинні бути в окремих модулях

### Модульна структура
- Кожен функціональний блок в окремому файлі
- Використання ES6 модулів
- Уникання дублювання коду

Детальні правила дивіться в [RULES.md](./RULES.md)

## Використання

1. Відкрийте `index.html` в браузері
2. Використовуйте панель шарів для створення нових шарів
3. Малюйте об'єкти за допомогою інструментів малювання
4. Редагуйте об'єкти подвійним кліком
5. Імпортуйте/експортуйте дані через кнопки в панелі шарів

### Пошук

#### Геопошук
- Введіть назву місця в поле "Пошук по геоназвах..."
- Результати з'являться з автодоповненням
- Клікніть на результат для центрування карти
- Використовуйте стрілки для навігації по результатах

#### Пошук об'єктів
- Введіть назву або опис об'єкта в поле "Пошук об'єктів"
- Результати групуються за типами (маркери, лінії, полігони, зображення)
- Клікніть на результат для виділення об'єкта на карті
- Об'єкт буде виділений на 3 секунди та карта центрується на ньому

## Технології

- **Leaflet.js** - інтерактивні карти
- **TypeScript** - типізований JavaScript
- **ES6 Modules** - модульна структура
- **localStorage** - збереження даних
- **Material Icons** - іконки
- **OpenStreetMap Nominatim API** - геопошук

## Тестування

### Тест пошуку
Відкрийте `test-search.html` для тестування функціональності пошуку:
- Геопошук з автодоповненням
- Пошук по тестових об'єктах
- Виділення об'єктів на карті

### Консоль браузера
```javascript
// Доступ до менеджера пошуку
window.searchManager

// Програмний пошук
searchManager.searchGeoLocation('Львів')
searchManager.searchObjects('парк')
```
