# Lefleat

**Lefleat** — це інтерактивний веб-додаток для роботи з мапою Львова на базі [Leaflet.js](https://leafletjs.com/). Проєкт написаний на **TypeScript**, зібраний через `tsc`, і призначений для створення, редагування та збереження географічних об’єктів прямо в браузері.

🌐 **Демо (локально):** відкрий `index.html` через `python3 -m http.server 8090` після збірки.

---

## Призначення

Lefleat створено для роботи з історичною та культурною географією Львова. Користувач може:

- позначати об’єкти на мапі (будівлі, пам’ятки, локації);
- малювати лінії, полігони та текстові позначки;
- зберігати роботу локально в браузері (`localStorage`);
- імпортувати та експортувати дані у форматах GeoJSON і KMZ;
- використовувати AI-асистента для швидкого пошуку та позначення місць.

## Основні можливості

| Фіча | Опис |
|------|------|
| 🗺️ Інтерактивна мапа | Мапа Львова на Leaflet із кількома типами підкладок |
| 📍 Маркери | Позначки місць із назвою, описом, кольором та іконкою |
| 📐 Лінії та полігони | Малювання контурів, маршрутів, периметрів |
| 📝 Текст на мапі | Текстові об’єкти, що масштабуються разом із мапою та обертаються мишкою |
| 🖼️ Зображення-оверлеї | Кастомний інтегрований `leaflet.distortableimage` для роботи зі зображеннями на мапі |
| 🤖 AI-асистент | Панель у кутку для пошуку місць через Nominatim і автоматичного додавання маркерів |
| 🔌 Програмний API | Глобальний `LefleatApi` для додавання маркерів, ліній, полігонів та тексту з консолі |
| 🔍 Геопошук | Пошук місць за назвою через OpenStreetMap / Nominatim |
| 📏 Вимірювання | Інструменти для вимірювання відстаней на мапі |
| 💾 Автозбереження | Всі дані зберігаються в `localStorage` браузера |
| 📤 Імпорт / Експорт | Підтримка GeoJSON та KMZ |
| 🎨 Кастомні іконки | Власна favicon та інтеграція Material Icons |

## Встановлення та запуск

```bash
# 1. Встановлення залежностей
npm install

# 2. Збірка TypeScript
npm run build

# 3. Локальний dev-сервер
npm run serve
```

Додаток буде доступний за адресою `http://localhost:8090`.

### Інші корисні команди

```bash
npm run lint          # перевірка ESLint
npm run lint:fix      # автоматичне виправлення ESLint
npm run format        # форматування Prettier
npm run check-rules   # lint + format check
npm run dev           # build + check-rules
```

## Використання

1. Відкрий додаток у браузері.
2. Створи новий шар у лівій панелі або використай активний.
3. Малюй об’єкти за допомогою панелі інструментів:
   - маркер,
   - лінія,
   - полігон,
   - текст (кастомна кнопка "Т"),
   - вимірювання.
4. Редагуй об’єкти подвійним кліком.
5. Використовуй AI-асистента для швидкого пошуку місць (наприклад, "Познач Чорну кам’яницю у Львові").
6. Зберігай або експортуй дані через панель шарів.

## Програмний API

Lefleat надає глобальний API у браузері:

```js
LefleatApi.addMarker(49.8424591, 24.0326305, {
  name: "Чорна Кам'яниця",
  description: "Кам'яниця Убальдіні, площа Ринок, 4",
  icon: 'place',
  color: '#1976d2',
});

LefleatApi.addText(49.8407294, 24.0310974, 'Каплиця Боїмів');

LefleatApi.addPolyline([[49.8428986, 24.0356783], [49.8422479, 24.0345786]], {
  name: 'Лінія між вежами',
  color: '#d84315',
});
```
