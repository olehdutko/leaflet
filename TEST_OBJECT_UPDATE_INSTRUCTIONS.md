# Інструкції для тестування оновлення списку об'єктів

## Проблема
Після зміни назви об'єкта список шару не оновлюється.

## Виправлення
1. Покращено логіку знаходження шару в `ModalService.updateUIAfterSave()`
2. Додано додаткові методи пошуку шару за `_leaflet_id`
3. Додано fallback на оновлення всіх шарів, якщо конкретний шар не знайдено
4. Додано детальне логування для діагностики

## Тестування

### Крок 1: Відкрийте тестовий файл
```
http://localhost:5173/test-object-edit.html
```

### Крок 2: Створіть тестовий сценарій
1. Додайте новий шар
2. Додайте маркер до шару
3. Подвійний клік на маркер для відкриття модального вікна
4. Змініть назву об'єкта
5. Натисніть "Оновити"

### Крок 3: Перевірте консоль
Відкрийте Developer Tools (F12) і перевірте консоль на наявність логів:
- `ModalService: saveObjectChanges викликано`
- `ModalService: updateUIAfterSave викликано`
- `ui.ts: updateObjectsListForLayer викликано для шару: [ID]`
- `ui.ts: renderObjectsList викликано для шару: [ID]`

### Крок 4: Запустіть тестовий скрипт
В консолі браузера виконайте:
```javascript
testObjectListUpdate()
```

### Крок 5: Перевірте результат
- Список об'єктів у панелі шарів повинен оновитися з новою назвою
- В консолі не повинно бути помилок
- Всі логі повинні показувати успішне виконання

## Діагностика

### Якщо список не оновлюється:
1. Перевірте, чи є логи в консолі
2. Перевірте, чи знайдено шар: `console.log(window.customLayers)`
3. Перевірте, чи зареєстровано функції оновлення: `console.log(window.layerIdToRenderObjectsList)`

### Якщо є помилки:
1. Перевірте, чи всі необхідні функції експортовані в глобальну область
2. Перевірте, чи правильно працює `saveLayersToStorage`
3. Перевірте, чи правильно знайдено шар для об'єкта

## Очікуваний результат
Після зміни назви об'єкта в модальному вікні та натискання "Оновити", список об'єктів у панелі шарів повинен миттєво оновитися з новою назвою.
