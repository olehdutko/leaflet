# Виправлення видалення overlay зображень

## Проблема
При видаленні зображень (overlay) з карти система не могла знайти overlay в системі шарів, що призводило до помилки "Overlay не знайдено в системі шарів".

## Причини проблеми
1. **Відсутність URL**: Overlay об'єкт не мав очікуваних URL властивостей (`_customUrl`, `_url`, `url`)
2. **Неправильна структура overlay**: Overlay об'єкт мав властивість `_overlay: e`, що вказувало на вкладену структуру
3. **Відсутність ID**: `_overlayId` також був `undefined`

## Виправлення (v3.4)

### 1. Розширена підтримка структур overlay
- Додано підтримку вкладених overlay об'єктів (`overlay._overlay`)
- Додано підтримку DOM елементів зображень (`overlay._image`)
- Покращено логіку отримання URL з різних джерел

### 2. Покращений пошук overlay
- Додано пошук за вкладеним `_overlay` об'єктом
- Розширено діагностичну інформацію в логах
- Додано підтримку різних структур даних

### 3. Резервне видалення
- Якщо overlay не знайдено в системі шарів, видаляємо його напряму з карти
- Додано очищення DOM елементів, пов'язаних з overlay
- Збереження змін в localStorage навіть при резервному видаленні

### 4. Виправлення посилання на карту
- Виправлено помилку `window.map.removeLayer is not a function`
- Використовуємо правильне посилання на об'єкт карти через імпорт
- Додано перевірку `map.hasLayer()` перед видаленням

### 5. Покращена діагностика
- Розширено логи для кращого розуміння структури overlay
- Додано інформацію про наявність вкладених об'єктів
- Покращено повідомлення про помилки

### 6. Діалог підтвердження видалення
- Додано діалог підтвердження перед видаленням зображення
- Використовується той самий діалог, що і для видалення шарів
- Зображення видаляється тільки після підтвердження користувача
- Кнопки "Видалити" та "Скасувати" для зручності

### 7. Виправлення помилок та стабільність
- Виправлено помилку `className.includes is not a function`
- Додано безпечне перетворення `className` та `id` в рядки через `String()`
- Додано обробку помилок з `try-catch` блоком
- Покращено стабільність функції очищення стану виділення

### 8. Агресивне очищення стану виділення
- Додано діагностику для пошуку всіх елементів редагування на сторінці
- Розширено список селекторів з використанням wildcard селекторів
- Додано агресивне очищення всіх знайдених елементів редагування
- Додано CSS стилі з `!important` для примусового приховування
- Додано очищення елементів в області карти
- Покращено логування для детальної діагностики

## Результат
Тепер система може успішно видаляти overlay зображень з діалогом підтвердження та стабільним автоматичним очищенням стану виділення без помилок.
