# 🎯 План оптимізації проекту Leaflet

## 📊 Поточний стан проекту

### ❌ **Критичні проблеми:**

#### **1. DRY (Don't Repeat Yourself) - Найбільші порушення:**
- **`saveLayersToStorage()` викликається 40+ разів** у різних файлах
- **Дублювання логіки `getObjectType`** - використовується в багатьох місцях
- **Повторювана логіка роботи з DOM** в `ui.ts` (пошук елементів, встановлення значень)
- **Дублювання логіки збереження властивостей** в `layers.ts` та `objects.ts`

#### **2. SRP (Single Responsibility Principle) - Порушення:**
- **`main.ts` (1926 рядків)** - містить все: overlay логіку, UI, геопошук, KMZ обробку
- **`ui.ts` (1415 рядків)** - містить все: модальні вікна, layer controls, tooltips, drag&drop
- **`layers.ts` (703 рядки)** - містить все: збереження, завантаження, UI оновлення

#### **3. KISS (Keep It Simple, Stupid) - Порушення:**
- **Складні функції з багатьма рівнями вкладеності** (особливо в `main.ts`)
- **Дуже довгі функції** (наприклад, `showEditModal` - 100+ рядків)
- **Складні умовні конструкції** з багатьма `if-else`
