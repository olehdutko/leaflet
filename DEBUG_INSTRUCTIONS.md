# 🐛 Інструкції для дебагінгу проблеми з дублюванням Overlay

## 🔧 **Виправлення версії 2.0 - Подвійний виклик loadLayersFromStorage**

### 🐛 **Знайдена основна причина дублювання:**

**Проблема:** В `main.ts` функція `loadLayersFromStorage()` викликалася **двічі**:
1. В `DOMContentLoaded` event listener  
2. Прямий виклик в секції "Ініціалізація"

**Виправлення:** Видалено подвійний виклик та додано захисні механізми:
- ✅ Видалено подвійний виклик `loadLayersFromStorage()` 
- ✅ Додано прапорець `_restoringOverlays` для захисту від повторних викликів
- ✅ Додано перевірку існування overlay в DOM перед створенням
- ✅ Покращено обробку помилок
- ✅ Виправлено логіку приховування/показування шарів з overlay
- ✅ При завантаженні приховані шари не додаються на карту

## 📋 Як перевірити, чи виправлена проблема

### 1. Відкрийте DevTools Console (F12)
- Переконайтесь, що консоль відкрита і видно логи

### 2. Додайте зображення через кнопку "Галерея"
- Натисніть кнопку галерея на картці шару
- Виберіть будь-яке зображення
- Спостерігайте за логами в консолі

**Очікувані логи:**
```

✅ Додано зображення в структури даних
💾 Збереження після додавання нового зображення
```

### 3. Редагуйте overlay (перетягніть/змініть розмір)
- Перетягніть зображення на карті
- Змініть розмір за кути

### 4. Тест приховування/показування шарів
- Натисніть кнопку "око" щоб сховати шар із зображенням
- Зображення має зникнути з карти
- Натисніть кнопку "око" ще раз щоб показати шар
- Зображення має з'явитися на карті у тому самому місці

**Очікувані логи:**
```

🙈 Знімаю з карти overlay restored_xxxxx
🧹 Очищую overlayInstances (залишаю тільки images для відновлення)
💾 Зберігаємо стан видимості шару "[назва шару]": false
👁️ Показую шар "[назва шару]" {overlayInstances: 0, images: 1}
🔄 overlayInstances пусті, відновлюю 1 images через restoreOverlaysForFeatureGroup
💾 Зберігаємо стан видимості шару "[назва шару]": true
🔄 Відновлення overlay для featureGroup {imagesCount: 1}
✅ Overlay додано на карту: restored_xxxxx
```

### 5. **Тест збереження стану видимості**
- Сховайте шар і перевантажте сторінку - шар має залишитися прихованим
- Покажіть шар і перевантажте сторінку - шар має залишитися видимим

**Очікувані логи:**
```

📝 Оновлено новий overlay new_xxxxx
💾 Збереження після додавання нового зображення
```

### 4. Використовуйте дебагінг функції

## 🔍 Діагностика проблем

### Якщо дублікати все ще з'являються:

1. **Перевірте логи створення overlay:**
   - Кожен overlay повинен мати унікальний ID
   - Не повинно бути повторюваних логів створення для одного зображення

2. **Перевірте логи edit подій:**
   - Edit події повинні спрацьовувати рідко (тільки при зміні)
   - Не повинно бути множинних edit подій за короткий час

3. **Перевірте structure даних:**
   ```javascript
   // В консолі браузера
   console.log('Custom layers:', customLayers.map(l => ({
     id: l.id,
     title: l.title,
     overlays: l.featureGroup.overlays?.length || 0,
     images: l.featureGroup.images?.length || 0,
     instances: l.featureGroup.overlayInstances?.length || 0
   })))
   ```

## 🛠️ Виправлення проблем

### Якщо дублікати в localStorage:
```javascript
// Очистити localStorage
localStorage.removeItem('lefleat_layers');
location.reload();
```

### Якщо дублікати на карті:
```javascript
// Видалити всі overlay з усіх шарів
customLayers.forEach(layer => {
  if (layer.featureGroup.overlayInstances) {
    layer.featureGroup.overlayInstances.forEach(ov => ov.remove());
    layer.featureGroup.overlayInstances = [];
  }
});
```

### Якщо логи показують помилки:
- Перевантажте сторінку
- Спробуйте додати зображення знову
- Перевірте, чи не блокує браузер LocalStorage

## 📝 Звіт про проблему
