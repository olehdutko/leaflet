# Функціональність додавання зображень до об'єктів

## Опис функціональності

Додано можливість прикріплювати зображення до об'єктів (ліній, полігонів, маркерів) з попереднім переглядом та автоматичним збереженням у localStorage.

## Основні можливості

### 1. Додавання зображень
- **Підтримувані типи об'єктів**: маркери, лінії, полігони, кола, прямокутники
- **Формати зображень**: всі формати, що підтримуються браузером (JPG, PNG, GIF, WebP, тощо)
- **Спосіб додавання**: через файловий інпут у вікні редагування об'єкта

### 2. Попередній перегляд
- **Мініатюра зображення**: відображається в модальному вікні редагування
- **Адаптивний розмір**: зображення масштабується під розмір контейнера
- **Максимальна висота**: 320px для зручності перегляду

### 3. Управління зображеннями
- **Видалення**: кнопка "Видалити зображення" для очищення
- **Автоматичне збереження**: зміни зберігаються в localStorage одразу після додавання/видалення
- **Відновлення**: зображення автоматично відновлюються при перезавантаженні сторінки

### 4. Відображення в тултіпах
- **Тултіпи об'єктів**: зображення відображаються в тултіпах при наведенні на об'єкт
- **Розмір в тултіпі**: максимум 180x120px для компактності
- **Адаптивність**: зображення масштабується зі збереженням пропорцій

## Технічна реалізація

### Структура даних
```typescript
// Властивості об'єкта
properties: {
  name: string,
  description: string,
  image: string, // base64 або URL зображення
  // інші властивості...
}
```

### Збереження в localStorage
- Зображення конвертуються в base64 формат
- Зберігаються разом з іншими властивостями об'єкта
- Автоматичне збереження при змінах

### UI компоненти
- **Файловий інпут**: `#object-image`
- **Контейнер попереднього перегляду**: `#object-image-preview-container`
- **Зображення попереднього перегляду**: `#object-image-preview`
- **Кнопка видалення**: `#object-image-remove`

## Використання

### 1. Додавання зображення
1. Двічі клікніть на об'єкт для відкриття вікна редагування
2. У розділі "Зображення" натисніть "Вибрати файл"
3. Виберіть зображення з комп'ютера
4. Зображення автоматично з'явиться в попередньому перегляді
5. Натисніть "Оновити" для збереження

### 2. Видалення зображення
1. Відкрийте вікно редагування об'єкта
2. Натисніть кнопку "Видалити зображення"
3. Зображення буде видалено з об'єкта

### 3. Перегляд зображення
- **В тултіпі**: наведіть курсор на об'єкт
- **У вікні редагування**: зображення відображається в попередньому перегляді

## Обмеження

1. **Розмір файлу**: браузерні обмеження на розмір base64 даних
2. **Продуктивність**: великі зображення можуть сповільнити завантаження
3. **localStorage**: обмеження на розмір даних (зазвичай 5-10 МБ)

## Рекомендації

1. **Оптимізація зображень**: використовуйте зображення розумного розміру
2. **Формат**: віддавайте перевагу WebP або оптимізованим JPG/PNG
3. **Розмір**: рекомендується не більше 1-2 МБ на зображення

## Майбутні покращення

1. **Стиснення зображень**: автоматичне зменшення розміру
2. **Хмарне зберігання**: завантаження зображень на сервер
3. **Галерея зображень**: можливість додавати кілька зображень до одного об'єкта
4. **Анотації**: можливість додавати підписи до зображень
