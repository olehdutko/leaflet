# Інструкції по налаштуванню правил проекту

## Що було зроблено

### 1. Створено нову структуру файлів
- **`index.ts`** - нова точка входу з тільки імпотами
- **`RULES.md`** - документація правил проекту
- **`.eslintrc.js`** - конфігурація ESLint з правилами
- **`.prettierrc`** - конфігурація форматування
- **`.gitignore`** - оновлений файл ігнорування

### 2. Оновлено `index.html`
- Змінено шлях з `./dist/main.js` на `./dist/index.js`

### 3. Додано npm скрипти
- `npm run build` - збірка проекту
- `npm run lint` - перевірка правил
- `npm run lint:fix` - автоматичне виправлення
- `npm run format` - форматування коду
- `npm run check-rules` - повна перевірка
- `npm run dev` - розробка (збірка + перевірка)

## Головне правило

### index.js/index.ts
- **В index.js НЕ повинно бути ніякого JS коду**
- **Тільки імпорти та мінімальна ініціалізація**
- Всі функції та логіка повинні бути в окремих модулях

## Як використовувати

### Для розробників
1. Всі нові функції додавати в окремі модулі
2. В `index.ts` тільки імпортувати необхідні модулі
3. Використовувати `npm run dev` для перевірки правил

### Для перевірки коду
```bash
# Перевірити правила
npm run lint

# Автоматично виправити
npm run lint:fix

# Форматувати код
npm run format

# Повна перевірка
npm run check-rules
```

### Для збірки
```bash
npm run build
```

## Структура файлів

```
lefleat/
├── index.html          # Головна сторінка
├── index.ts            # Точка входу (тільки імпорти) ⭐ НОВИЙ
├── main.ts             # Основний код додатку
├── layers.ts           # Управління шарами
├── ui.ts               # UI компоненти
├── state.ts            # Глобальний стан
├── utils.ts            # Утиліти
├── draw-control.ts     # Контроль малювання
├── map-init.ts         # Ініціалізація карти
├── overlay-transform.ts # Трансформація overlay
├── objects.ts          # Об'єкти карти
├── style.css           # Стилі
├── RULES.md            # Правила проекту ⭐ НОВИЙ
├── .eslintrc.js        # ESLint конфігурація ⭐ НОВИЙ
├── .prettierrc         # Prettier конфігурація ⭐ НОВИЙ
├── .gitignore          # Оновлений
├── package.json        # Оновлений з новими скриптами
└── del/                # Дебаг файли
```

## Переваги нової структури

1. **Чітка точка входу** - `index.ts` містить тільки імпорти
2. **Автоматична перевірка** - ESLint контролює правила
3. **Форматування** - Prettier забезпечує консистентність
4. **Документація** - `RULES.md` містить всі правила
5. **Модульність** - кожен функціональний блок в окремому файлі

## Наступні кроки

1. Встановити залежності: `npm install`
2. Запустити перевірку: `npm run check-rules`
3. Виправити помилки якщо є: `npm run lint:fix`
4. Продовжувати розробку з дотриманням правил
