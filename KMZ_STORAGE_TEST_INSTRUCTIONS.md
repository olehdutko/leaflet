# Інструкції для тестування збереження KMZ в localStorage

## Проблема
Об'єкти відображаються з іменами після імпорту KMZ файлу, але імена пропадають після оновлення сторінки, оскільки вони не зберігаються в localStorage.

## Рішення
Додано функціональність збереження feature об'єктів з метаданими в localStorage та їх відновлення при перезавантаженні сторінки.

## Тестування

### Варіант 1: Простий тестовий файл
```
http://localhost:8001/test-kmz-simple.html
```

### Варіант 2: Основний додаток
```
http://localhost:8001/test-kmz-storage.html
```

## Сценарій тестування

### Крок 1: Імпорт KMZ файлу
1. Відкрийте тестовий файл
2. Виберіть KMZ файл для імпорту
3. Натисніть "Імпортувати KMZ"
4. Дочекайтеся завершення імпорту

### Крок 2: Перевірка відображення
- Об'єкти повинні з'явитися на карті з іменами
- В панелі шарів повинні відображатися назви об'єктів

### Крок 3: Перевірка збереження в localStorage
В консолі браузера повинні з'явитися логи:
- "Зберігаємо в localStorage..."
- "Зберігаємо feature об'єкт: {...}"
- "Підсумок збереження: {...}"
- "Дані збережено в localStorage: {...}"

### Крок 4: Перевірка localStorage
Натисніть кнопку "Перевірити localStorage" або в консолі виконайте:
```javascript
checkLocalStorage()
```

### Крок 5: Тест перезавантаження
1. Перезавантажте сторінку (F5)
2. Перевірте, чи відновилися об'єкти з іменами
3. Перевірте консоль на логи відновлення

### Крок 6: Діагностика
В консолі браузера виконайте:
```javascript
checkStorageAfterImport()
compareMemoryAndStorage()
testPageReload()
```

## Очікуваний результат

### Після імпорту:
- ✅ Об'єкти відображаються з іменами
- ✅ Feature об'єкти створюються з properties
- ✅ Дані зберігаються в localStorage
- ✅ Логи показують успішне збереження

### Після перезавантаження:
- ✅ Об'єкти відновлюються з іменами
- ✅ Properties відновлюються правильно
- ✅ Feature об'єкти відновлюються з метаданими
- ✅ Логи показують успішне відновлення

## Діагностика проблем

### Якщо імена не зберігаються:
1. Перевірте, чи є логи "Зберігаємо feature об'єкт"
2. Перевірте, чи створюються feature об'єкти з properties
3. Перевірте, чи викликається saveLayersToStorage

### Якщо імена не відновлюються:
1. Перевірте, чи є дані в localStorage
2. Перевірте, чи правильно парсяться feature об'єкти
3. Перевірте, чи відновлюються properties

### Якщо є помилки:
1. Перевірте консоль на помилки
2. Перевірте, чи правильно працює JSON.parse
3. Перевірте, чи правильно створюються Leaflet об'єкти

## Технічні деталі

### Процес збереження:
1. KMZ сервіс створює Leaflet об'єкти з feature та properties
2. saveLayersToStorage перебирає всі об'єкти в featureGroup
3. Якщо є layer.feature - використовує його
4. Створює GeoJSON FeatureCollection
5. Зберігає в localStorage

### Процес відновлення:
1. При завантаженні сторінки читаємо localStorage
2. Парсимо GeoJSON FeatureCollection
3. Створюємо Leaflet об'єкти з feature та properties
4. Додаємо до карти та панелі шарів
