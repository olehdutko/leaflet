# Інструкції для тестування виправлення проблеми з властивостями KMZ об'єктів

## Проблема
При імпорті KMZ файлу через основну аплікацію об'єкти шару мають пусті властивості `properties: {}`, хоча в тесті вони правильні.

## Виправлення
1. **Виправлено функцію `saveLayersToStorage` в `layers.ts`**:
   - Додано перевірку на існуючі властивості перед їх перезаписом
   - Властивості з KMZ сервісу тепер не перезаписуються дефолтними значеннями
   - Додано логування для діагностики

2. **Виправлено KMZ сервіс**:
   - Виправлено встановлення стилю для LineString об'єктів
   - Додано логування створення властивостей

## Тестування

### Крок 1: Відкрийте тестовий файл
```
test-kmz-properties-fix.html
```

### Крок 2: Імпортуйте KMZ файл
1. Натисніть кнопку "Імпорт"
2. Виберіть KMZ файл з тестовими даними
3. Дочекайтеся завершення імпорту

### Крок 3: Перевірте консоль браузера
Відкрийте Developer Tools (F12) і перевірте консоль. Ви повинні побачити:

1. **Логи з KMZ сервісу**:
   ```
   KmzService: Створюємо Point з властивостями: {name: "...", description: "...", color: "#1976d2", icon: "place"}
   KmzService: Створюємо LineString з властивостями: {name: "...", description: "...", color: "#1976d2", weight: 3, opacity: 1, style: "solid"}
   ```

2. **Логи з layers.ts**:
   ```
   layers.ts: Зберігаємо feature об'єкт: {type: "Point", name: "...", hasName: true}
   ```

3. **Результати тестування**:
   ```
   === ТЕСТ ВИПРАВЛЕННЯ ВЛАСТИВОСТЕЙ KMZ ===
   === ПОРІВНЯННЯ ВЛАСТИВОСТЕЙ В ПАМ'ЯТІ ТА LOCALSTORAGE ===
   === ПРИМУСОВЕ ЗБЕРЕЖЕННЯ ТА ПЕРЕВІРКА ===
   ```

### Крок 4: Перевірте властивості об'єктів
В консолі ви повинні побачити, що властивості об'єктів тепер зберігаються правильно:

```javascript
// В пам'яті
Властивості в пам'яті: {
  name: "•\t3.1.2. На повороті від костелика Святого Хреста",
  description: "",
  color: "#1976d2",
  weight: 3,
  opacity: 1,
  style: "solid"
}

// В localStorage
Властивості в localStorage: {
  name: "•\t3.1.2. На повороті від костелика Святого Хреста",
  description: "",
  color: "#1976d2",
  weight: 3,
  opacity: 1,
  style: "solid"
}
```

### Крок 5: Перевірте основну аплікацію
1. Відкрийте основну аплікацію (`index.html`)
2. Імпортуйте той самий KMZ файл
3. Перевірте, що властивості об'єктів тепер зберігаються правильно

## Очікуваний результат
- Властивості об'єктів з KMZ файлу повинні зберігатися правильно як в пам'яті, так і в localStorage
- Не повинно бути пустих `properties: {}`
- Всі властивості (name, description, color, weight, opacity, style) повинні зберігатися

## Додаткові функції для тестування
В консолі браузера доступні функції:
- `testKmzPropertiesFix()` - основний тест
- `compareMemoryAndStorageProperties()` - порівняння пам'яті та localStorage
- `forceSaveAndCheck()` - примусове збереження та перевірка
