# Інструкція для тестування нових сервісів в браузері

## 🧪 Як протестувати нові сервіси

### 1. Відкриття тестової сторінки

Файл `test-browser.html` вже відкрито в браузері. Якщо потрібно відкрити знову:

```bash
open test-browser.html
```

### 2. Структура тестової сторінки

Сторінка містить 7 основних розділів:

1. **Базові DOM утиліти** - тестування роботи з DOM елементами
2. **Storage Service** - тестування localStorage
3. **Object Service** - тестування роботи з об'єктами (моки)
4. **Типи та інтерфейси** - тестування TypeScript структур
5. **Legacy Adapter** - тестування адаптера для міграції
6. **Інтеграційний тест** - тестування всіх сервісів разом
7. **Консоль** - логування результатів тестів

### 3. Порядок тестування

#### Крок 1: Перевірка готовності
- Переконайтеся, що статус показує "✅ Готово до тестування!"
- Якщо статус червоний, перезавантажте сторінку

#### Крок 2: Індивідуальні тести
Натисніть кнопки в такому порядку:

1. **"Тестувати базові DOM утиліти"**
   - Перевіряє: `getElementById`, `setElementText`, `setInputValue`, `getInputValue`, `setElementVisibility`
   - Очікуваний результат: Всі тести зеленим кольором ✅

2. **"Тестувати Storage Service"**
   - Перевіряє: `saveLayers`, `loadLayers`, `hasLayers`, `clearLayers`
   - Очікуваний результат: Всі тести зеленим кольором ✅

3. **"Тестувати Object Service"**
   - Перевіряє: `getObjectProperties`, `setObjectProperty`, `getObjectType`
   - Очікуваний результат: Всі тести зеленим кольором ✅

4. **"Тестувати типи"**
   - Перевіряє: `LayerObj`, `ObjectProperties`, `ModalConfig` структури
   - Очікуваний результат: Всі тести зеленим кольором ✅

5. **"Тестувати Legacy Adapter"**
   - Перевіряє: адаптер для зворотної сумісності
   - Очікуваний результат: Всі тести зеленим кольором ✅

#### Крок 3: Інтеграційний тест
Натисніть **"Запустити всі тести"** для комплексного тестування.

### 4. Інтерпретація результатів

#### ✅ Успішні тести (зелений колір):
- Функціональність працює коректно
- Можна переходити до наступного тесту

#### ❌ Помилки (червоний колір):
- Функціональність не працює
- Перевірте консоль браузера для деталей

### 7. Усунення проблем

#### Проблема: Сторінка не завантажується
**Рішення:**
- Перевірте, чи файл `test-browser.html` існує
- Відкрийте файл безпосередньо в браузері: `file:///path/to/test-browser.html`

#### Проблема: Тести не проходять
**Рішення:**
- Перезавантажте сторінку (`Cmd + R`)
- Очистіть кеш браузера
- Перевірте консоль на помилки

#### Проблема: localStorage не працює
**Рішення:**
- Перевірте, чи localStorage увімкнено в браузері
- Спробуйте в режимі інкогніто
- Перевірте налаштування приватності браузера

### 8. Наступні кроки після успішного тестування

Якщо всі тести пройшли успішно:

1. **Переходимо до Етапу 2** - інтеграція з існуючим кодом
2. **Використовуємо LegacyAdapter** для поступової міграції
3. **Тестуємо на реальних даних** проекту
4. **Моніторимо продуктивність** під час міграції

### 9. Зворотний зв'язок

Якщо виникли проблеми або є питання:
