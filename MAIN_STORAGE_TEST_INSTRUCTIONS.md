# Інструкції для тестування збереження в основній аплікації

## Проблема
Дані з KMZ файлу зберігаються в localStorage у простому тесті, але не зберігаються в основній аплікації.

## Виправлення
Додано виклики `appManager.updateSaveFunction()` та `appManager.updateLayers()` в основній аплікації для забезпечення синхронізації з KmzService.

## Тестування

### Крок 1: Запуск тесту
1. Відкрийте `http://localhost:8001/test-main-storage.html`
2. Дочекайтеся повідомлення "✅ Тест готовий до використання"

### Крок 2: Діагностика
1. Натисніть **"Тест AppManager"** - перевірить стан AppManager
2. Натисніть **"Тест KmzService"** - перевірить стан KmzService
3. Натисніть **"Тест функції збереження"** - перевірить функцію збереження

### Крок 3: Імпорт KMZ
1. Виберіть KMZ файл
2. Натисніть **"Імпортувати KMZ"**
3. Дочекайтеся повідомлення про успішний імпорт
4. Автоматично запуститься перевірка localStorage

### Крок 4: Перевірка збереження
1. Натисніть **"Перевірити localStorage"** - побачите збережені дані
2. Перевірте, чи є назви об'єктів в localStorage

### Крок 5: Тест відновлення
1. Натисніть **"Перезавантажити сторінку"**
2. Дочекайтеся повторної ініціалізації
3. Перевірте, чи відновилися об'єкти з назвами

## Діагностичні кнопки

### Тест AppManager
- Перевіряє ініціалізацію AppManager
- Показує список сервісів
- Показує поточний стан

### Тест KmzService
- Перевіряє ініціалізацію KmzService
- Показує тип сервісу
- Підтверджує доступність

### Тест функції збереження
- Перевіряє глобальну функцію `saveLayersToStorage`
- Перевіряє імпортовану функцію
- Тестує виклик функції збереження

## Логи в консолі браузера

Додатково перевірте консоль браузера (F12) на наявність логів:
- `KmzService: Викликаємо saveLayersToStorage...`
- `KmzService: saveLayersToStorage викликано`
- `layers.ts: saveLayersToStorage викликано`

## Виправлення в коді

### 1. main.ts
```typescript
// Додано виклик updateSaveFunction
appManager.updateSaveFunction(saveLayersToStorage);
```

### 2. layers.ts
```typescript
// Додано оновлення AppManager в addLayer
appManager.updateLayers(customLayers);

// Додано оновлення AppManager в loadLayersFromStorage
appManager.updateLayers(customLayers);

// Додано оновлення AppManager в saveLayersToStorage
appManager.updateLayers(customLayers);
```

## Наступні кроки
