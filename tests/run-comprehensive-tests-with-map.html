🧪 Комплексні тести з картою - Lefleat

Повне тестування функціональності з інтерактивною картою

Інструкції:
  • Карта ініціалізована для повного тестування
  • Використовуйте кнопки для запуску різних груп тестів
  • Результати відображатимуться в консолі
  • Тести можуть взаємодіяти з картою
Готовий до тестування з картою! 🚀 Натисніть кнопку "Запустити всі тести" або виберіть окрему групу тестів.
