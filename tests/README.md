## 🚀 Як запустити тести

### 1. Автономні тести (рекомендовано)

Відкрийте `run-comprehensive-tests.html` у браузері для запуску автономних тестів без залежності від карти:

```bash
# Або через локальний сервер
python -m http.server 8000
# Потім відкрийте http://localhost:8000/tests/run-comprehensive-tests.html
```

**Переваги автономних тестів:**
- ✅ Не залежать від ініціалізації карти Leaflet
- ✅ Швидко запускаються
- ✅ Покривають основну логіку
- ✅ Не потребують додаткових залежностей

### 2. Комплексні тести з картою

Відкрийте `run-comprehensive-tests-with-map.html` для повного тестування з інтерактивною картою:

```bash
open tests/run-comprehensive-tests-with-map.html
```

**Переваги тестів з картою:**
- ✅ Повне покриття функціональності
- ✅ Тестування взаємодії з картою
- ✅ Інтеграційне тестування
- ✅ Візуальна перевірка результатів

### 3. Окремі тести

Відкрийте будь-який HTML файл тесту у браузері:

```bash
# Приклад
open tests/test-main-integration.html
```

### 4. Запуск через консоль

```javascript
// Автономні тести
import('./tests/standalone-tests.js').then(module => {
    module.runAllStandaloneTests(); // Всі автономні тести
    // або
    module.runStandaloneTestGroup('utils'); // Окрема група
});

// Комплексні тести (потребують карти)
import('./tests/comprehensive-tests.js').then(module => {
    module.runAllTests(); // Всі тести
    // або
    module.runTestGroup('layers'); // Окрема група
});
```

## 🐛 Відладка

### Часті проблеми
1. **Помилки імпорту** - Перевірте шляхи до модулів
2. **CORS помилки** - Запускайте через локальний сервер
3. **Leaflet не завантажений** - Використовуйте автономні тести
4. **Помилки карти** - Перевірте наявність елемента `#map`

### Логи
- Всі тести виводять детальні логи в консоль
- Використовуйте F12 для перегляду логів браузера
- Провалені тести показують деталі помилок
