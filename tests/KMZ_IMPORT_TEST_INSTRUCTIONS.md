# Інструкції для тестування KMZ імпорту

## Проблема
Після імпортування KMZ файлу об'єкти відображаються в панелі шарів з іменами, але в localStorage ці імена відсутні.

## Виправлення
1. Додано створення `feature` об'єктів в KMZ сервісі
2. Покращено збереження метаданих об'єктів
3. Додано детальне логування для діагностики

## Тестування

### Крок 1: Відкрийте тестовий файл
```
http://localhost:8002/test-kmz-import.html
```

### Крок 2: Імпортуйте KMZ файл
1. Натисніть кнопку "Імпорт" в панелі шарів
2. Виберіть KMZ файл для імпорту
3. Дочекайтеся завершення імпорту

### Крок 3: Перевірте консоль
Відкрийте Developer Tools (F12) і перевірте консоль на наявність логів:
- `KmzService: Знайдено placemarks: [кількість]`
- `KmzService: Створено об'єкт [номер]: {...}`
- `KmzService: Додаємо шар: {...}`
- `layers.ts: Зберігаємо feature об'єкт: {...}`
- `layers.ts: Підсумок збереження для шару: {...}`

### Крок 4: Запустіть тестовий скрипт
В консолі браузера виконайте:
```javascript
testKmzImport()
```

### Крок 5: Порівняйте дані
В консолі браузера виконайте:
```javascript
compareMemoryAndStorage()
```

### Крок 6: Перевірте результат
- Об'єкти повинні відображатися в панелі шарів з іменами
- Імена повинні зберігатися в localStorage
- Всі логі повинні показувати успішне створення feature об'єктів
- Порівняння пам'яті та localStorage повинно показувати синхронізацію

## Діагностика

### Якщо імена не зберігаються в localStorage:
1. Перевірте, чи є логи `KmzService: Створено об'єкт`
2. Перевірте, чи є логи `layers.ts: Зберігаємо feature об'єкт`
3. Перевірте, чи створюються `feature` об'єкти з `properties`

### Якщо є помилки:
1. Перевірте, чи правильно парсяться KML дані
2. Перевірте, чи правильно створюються Leaflet об'єкти
3. Перевірте, чи правильно викликається `saveLayersToStorage`

### Якщо об'єкти не відображаються:
1. Перевірте, чи додаються об'єкти до `featureGroup`
2. Перевірте, чи правильно працює `renderObjectsList`
3. Перевірте, чи правильно застосовуються стилі

## Очікуваний результат
Після імпорту KMZ файлу:
- ✅ Об'єкти відображаються в панелі шарів з іменами
- ✅ Імена зберігаються в localStorage
- ✅ Feature об'єкти створюються з правильними properties
- ✅ Дані синхронізовані між пам'яттю та localStorage

## Додаткові тести

### Тест редагування об'єкта
1. Подвійний клік на об'єкт в панелі шарів
2. Змініть назву об'єкта
3. Натисніть "Оновити"
4. Перевірте, що список оновився
5. Перевірте, що зміни збереглися в localStorage

### Тест перезавантаження сторінки
1. Імпортуйте KMZ файл
2. Перезавантажте сторінку
3. Перевірте, що об'єкти відновилися з іменами
4. Перевірте, що localStorage містить правильні дані
