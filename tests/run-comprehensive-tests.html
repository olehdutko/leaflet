🧪 Автономні тести - Lefleat

Тестування функціональності без залежності від карти Leaflet

Інструкції:
  • Натисніть "Запустити всі автономні тести" для повного тестування
  • Або виберіть окрему групу тестів
  • Результати відображатимуться в консолі нижче
  • Ці тести не залежать від ініціалізації карти Leaflet

📋 Доступні групи автономних тестів:

  • utils - Тести утиліт та допоміжних функцій
  • storage - Тести localStorage операцій
  • modal - Тести модальних вікон та форм
  • icons - Тести Material Icons
  • appmanager - Тести AppManager та сервісів
  • ui - Тести UI компонентів
  • integration - Інтеграційні тести workflow
Готовий до тестування! 🚀 Натисніть кнопку "Запустити всі тести" або виберіть окрему групу тестів.
