# Виправлення імпорту KMZ з метаданими

## Проблема
При імпортуванні KMZ файлів об'єкти імпортувалися, але не імпортувалися імена та описи об'єктів.

## Рішення
Оновлено `KmzService` для правильного парсингу метаданих з KML файлів.

### Основні зміни

#### 1. Парсинг метаданих об'єктів
- Додано парсинг елементів `<name>` та `<description>` з кожного `<Placemark>`
- Метадані зберігаються в властивості `properties` кожного об'єкта

#### 2. Парсинг стилів
- Додано метод `parsePlacemarkStyle()` для парсингу вбудованих стилів
- Додано метод `parseGlobalStyles()` для парсингу глобальних стилів з `<Style>` та `<StyleMap>`
- Додано метод `parseStyleElement()` для обробки окремих стильових елементів

#### 3. Конвертація кольорів
- Додано метод `convertKmlColor()` для конвертації KML кольорів (формат AABBGGRR) в hex формат
- Підтримка прозорості та різних кольорових схем

#### 4. Покращена обробка геометрій
- Оновлено `parsePlacemarkGeometry()` для включення метаданих та стилів
- Підтримка Point, LineString та Polygon з повними метаданими

### Підтримувані елементи KML

#### Метадані
- `<name>` - назва об'єкта
- `<description>` - опис об'єкта (підтримує HTML)

#### Стилі
- `<IconStyle>` - стилі для маркерів
- `<LineStyle>` - стилі для ліній
- `<PolyStyle>` - стилі для полігонів
- `<Style>` - глобальні стилі
- `<StyleMap>` - карти стилів

#### Геометрії
- `<Point>` - точки/маркери
- `<LineString>` - полілінії
- `<Polygon>` - полігони

### Приклад використання

```typescript
// Імпорт KMZ файлу з метаданими
await kmzService.handleKmzFile(file, {
  onSuccess: (layerConfig) => {
    console.log('Імпортовано:', layerConfig.title);
    
    // Перевірка метаданих об'єктів
    layerConfig.featureGroup.getLayers().forEach(layer => {
      console.log('Об\'єкт:', layer.properties?.name);
      console.log('Опис:', layer.properties?.description);
      console.log('Колір:', layer.properties?.color);
    });
  }
});
```

### Результат

Тепер при імпорті KMZ файлів:
- ✅ Імпортуються імена об'єктів
- ✅ Імпортуються описи об'єктів
- ✅ Імпортуються стилі (кольори, товщина ліній, тощо)
- ✅ Підтримуються глобальні стилі
- ✅ Правильна конвертація кольорів

Всі метадані зберігаються в властивості `properties` об'єктів і доступні для подальшого використання в інтерфейсі редагування.
