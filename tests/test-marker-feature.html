Тест створення feature для маркерів

Інструкції:

  1. Створіть маркер на карті (кнопка маркера в правому верхньому куті)
  2. Перевірте консоль браузера для логів створення feature
  3. Подвійний клік на маркері для відкриття вікна редагування
  4. Змініть іконку на "home"
  5. Натисніть "Оновити"
  6. Перевірте консоль для логів збереження
  7. Натисніть кнопку "Перевірити localStorage"
