# 📋 Інструкції для тестування інтеграції DOM утиліт в main.ts

## 🎯 Мета тестування

Перевірити, що інтеграція DOM утиліт в `main.ts` (Частина 1) працює коректно та не порушила існуючу функціональність.

## 🚀 Запуск тестування

### Крок 1: Запуск сервера розробки
```bash
npm run dev
```
Сервер запуститься на `http://localhost:8000`

### Крок 2: Відкриття тестової сторінки
Відкрийте в браузері:
```
http://localhost:8000/test-main-integration.html
```

## 🧪 Доступні тести

### 1. Тест компіляції та завантаження
- **Тест компіляції**: Перевіряє, чи завантажився LegacyAdapter
- **Тест завантаження модулів**: Перевіряє наявність всіх необхідних методів

### 2. Тест LegacyAdapter
- **Тест DOM адаптера**: Перевіряє основні функції getElement та setText
- **Тест нових методів**: Перевіряє clearElementContent та setInnerHTML

### 3. Тест DOM операцій
- **Тест getElement**: Перевіряє отримання елементів за ID
- **Тест setText**: Перевіряє встановлення тексту
- **Тест setInputValue**: Перевіряє встановлення значень input
- **Тест clearElementContent**: Перевіряє очищення контенту

### 4. Тест функціональності main.ts
- **Тест основних функцій**: Перевіряє доступність функцій з main.ts
- **Тест модальних вікон**: Перевіряє роботу модальних вікон

### 5. Інтеграційний тест
- **Запустити повний тест**: Автоматично запускає всі тести
- **Очистити результати**: Очищує всі результати

## 📊 Очікувані результати

### ✅ Успішні результати:
- Всі тести показують зелені галочки ✅
- В консолі немає помилок
- LegacyAdapter завантажується успішно
- Всі DOM операції працюють коректно

### ❌ Проблемні результати:
- Тести показують червоні хрестики ❌
- В консолі є помилки
- LegacyAdapter не завантажується
- DOM операції не працюють

### Перевірка нових методів:
1. Натисніть "Тест нових методів"

1. Натисніть кожен тест окремо або "Запустити повний тест"

## 🚨 Вирішення проблем

### Проблема: LegacyAdapter не завантажується
**Рішення:**
1. Перевірте, чи скомпілювався проект: `npm run build`
2. Перевірте, чи існує файл `dist/adapters/legacy-adapter.js`
3. Перевірте консоль браузера на помилки

### Проблема: DOM операції не працюють
**Рішення:**
1. Перевірте, чи правильно імпортований LegacyAdapter в main.ts
2. Перевірте, чи всі методи присутні в LegacyAdapter
3. Перевірте консоль браузера на помилки

### Проблема: Тести не запускаються
**Рішення:**
1. Перевірте, чи запущений сервер розробки
2. Перевірте, чи доступна сторінка `http://localhost:8000/test-main-integration.html`
3. Перевірте консоль браузера на помилки

## 📝 Логування

## 🎯 Критерії успіху

Тестування вважається успішним, якщо:
- ✅ Всі тести пройшли без помилок
- ✅ LegacyAdapter завантажується коректно
- ✅ Всі DOM операції працюють
- ✅ Немає помилок в консолі браузера
- ✅ Функціональність main.ts не порушена
