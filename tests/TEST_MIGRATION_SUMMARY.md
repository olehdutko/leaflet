## 🛠️ Інструменти тестування

### TestUtils клас
```typescript
class TestUtils {
  static assert(condition, message, details?)
  static assertEqual(actual, expected, message)
  static assertNotNull(value, message)
  static assertTrue(condition, message)
  static assertFalse(condition, message)
  static createMockLayer(type, properties)
  static createMockFeatureGroup()
  static clearLocalStorage()
  static getLocalStorageData()
  static setLocalStorageData(data)
}
```

### Групи тестів
```typescript
// Запуск всіх тестів
runAllTests()

// Запуск окремої групи
runTestGroup('layers')     // Тести шарів
runTestGroup('objects')    // Тести об'єктів
runTestGroup('storage')    // Тести localStorage
runTestGroup('modal')      // Тести модальних вікон
runTestGroup('integration') // Інтеграційні тести
```
