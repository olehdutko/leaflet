# Інструкції для діагностики проблеми з властивостями KMZ

## Проблема
Після імпорту KMZ файлу властивості об'єктів все ще порожні: `properties: {}`

## Діагностика

### Крок 1: Відкрийте тестовий файл
```
test-kmz-debug.html
```

### Крок 2: Імпортуйте KMZ файл
1. Натисніть кнопку "Імпорт"
2. Виберіть KMZ файл з тестовими даними
3. Дочекайтеся завершення імпорту

### Крок 3: Перевірте консоль браузера
Відкрийте Developer Tools (F12) і перевірте консоль. Ви повинні побачити:

1. **Детальну діагностику об'єктів**:
   ```
   === ДЕТАЛЬНА ДІАГНОСТИКА KMZ ОБ'ЄКТІВ ===
   --- Шар 0: "KMZ шар" ---
   Кількість об'єктів: X
   
     Об'єкт 1:
       Тип: L.Marker
       Має feature: true
       Має properties: true
       feature.properties: {...}
       layer.properties: {...}
   ```

2. **Перевірку localStorage**:
   ```
   === ПЕРЕВІРКА LOCALSTORAGE ===
   Знайдено X шарів в localStorage
   
     Шар 0: "KMZ шар"
       Кількість features: X
         Feature 1:
           Тип: Point
           Properties: {...}
   ```

3. **Примусове збереження**:
   ```
   === ПРИМУСОВЕ ЗБЕРЕЖЕННЯ ТА ДІАГНОСТИКА ===
   Викликаємо saveLayersToStorage...
   Перевіряємо результат...
   ```

4. **Створення тестового об'єкта**:
   ```
   === СТВОРЕННЯ ТЕСТОВОГО ОБ'ЄКТА ===
   Створено тестовий об'єкт: {...}
   Тестовий об'єкт додано до шару
   Збережено після додавання тестового об'єкта
   ```

### Крок 4: Аналіз результатів

**Якщо ви бачите попередження:**
```
⚠️ ПРОБЛЕМА: feature.properties порожній, але layer.properties має дані!
```

Це означає, що властивості створюються правильно в `layer.properties`, але не копіюються в `layer.feature.properties`.

**Якщо ви бачите:**
```
⚠️ ПРОБЛЕМА: Properties порожні!
```

Це означає, що властивості взагалі не створюються.

### Крок 5: Додаткові функції в консолі

В консолі браузера доступні функції:
- `debugKmzObjects()` - детальна діагностика об'єктів
- `debugLocalStorage()` - перевірка localStorage
- `forceSaveAndDebug()` - примусове збереження та перевірка
- `createTestObject()` - створення тестового об'єкта

## Очікувані результати

### Правильний результат:
```javascript
feature.properties: {
  name: "•\t3.1.2. На повороті від костелика Святого Хреста",
  description: "",
  color: "#1976d2",
  weight: 3,
  opacity: 1,
  style: "solid"
}

layer.properties: {
  name: "•\t3.1.2. На повороті від костелика Святого Хреста",
  description: "",
  color: "#1976d2",
  weight: 3,
  opacity: 1,
  style: "solid"
}
```

### Проблемний результат:
```javascript
feature.properties: {}
layer.properties: {
  name: "•\t3.1.2. На повороті від костелика Святого Хреста",
  description: "",
  color: "#1976d2",
  weight: 3,
  opacity: 1,
  style: "solid"
}
```
