Тест виправлення помилки іконки

Інструкції:

  1. Створіть маркер на карті (кнопка маркера в правому верхньому куті)
  2. Подвійний клік на маркері для відкриття вікна редагування
  3. Змініть іконку на "home"
  4. Натисніть "Оновити"
  5. Перевірте консоль для логів та помилок
